# Repository instructions

Lead with the result or current status. Use plain English. Explain what changed, why, and how it was verified. Separate facts, assumptions, recommendations, and unknowns. Never claim completion without evidence.

This repository packages portable agent skills. Keep every skill focused, provider-neutral where practical, and progressively disclosed. Do not add external services or credentials to examples. Validate skills and the installer after changes.

Preserve license notices and record source revisions in `docs/SKILL_SOURCES.md`.
