# Workflow

1. Inspect the repository.
2. Run `product-interview` and approve the brief.
3. Run `master-plan` and approve the plan.
4. Let `task-orchestrator` produce a dependency graph and approve it.
5. Run up to three non-overlapping tasks concurrently.
6. Review handoffs and integrate through the lead agent.
7. Run builds, tests, runtime checks, and evidence capture.
8. Apply text or visual feedback with `refine-result`.
9. Issue a final report that distinguishes passed, failed, partial, and untested criteria.

Execution stops only for material choices or risky external actions, not merely because a subtask finished.
