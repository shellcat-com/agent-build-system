# Mobbin MCP

Mobbin's official hosted MCP endpoint is:

```text
https://api.mobbin.com/mcp
```

It uses Streamable HTTP and OAuth. There is no local server to clone and no API key to commit. Configure each client, restart it if required, then complete the browser sign-in on first use.

The installer does not edit MCP configuration. Follow the client guide in this folder and verify the commands against your installed client version.

Use Mobbin to research flows and patterns. Do not copy a product screen, wording, illustrations, or brand identity. Do not send secrets, source code, customer data, or unreleased details in search queries.

Official source: https://github.com/mobbin/mobbin-mcp-server
