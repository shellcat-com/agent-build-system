# T3 Code

T3 Code coordinates threads and underlying harnesses. Repository-local skills remain the portable source of behavior.

- Start a Codex or Claude Code thread in the project containing `.agents/skills/` and the matching Claude links.
- Keep the lead integration thread responsible for the master plan, task graph, shared interfaces, and final evidence.
- Run at most three independent implementation agents concurrently.
- Use T3's attached preview/browser for browser work when available.
- Do not assume separate threads isolate databases, simulators, ports, deployments, or external accounts.
