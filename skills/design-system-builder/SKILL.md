# Design system builder

Inspect the product, platform, existing UI, assets, and approved research. Create or revise the project-root `DESIGN.md` using the bundled template.

Define relationships before literal values: hierarchy, contrast, density, warmth, restraint, and emotional intensity. Then specify named tokens for color, typography, spacing, radius, depth, materials, imagery, iconography, motion, and haptics. Cover component and interaction states, responsive/adaptive behavior, accessibility, and reduced effects.

Use references to learn principles, not to reproduce a brand. Cite inspirations and explain the transformation into an original identity. Do not use proprietary logos, fonts without a license, or copied signature components.

The project `DESIGN.md` becomes the visual source of truth. Platform skills translate it into native implementation.
