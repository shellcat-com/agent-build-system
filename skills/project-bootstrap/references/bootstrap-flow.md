# Bootstrap flow

1. Inspect and inventory.
2. Choose user or project scope.
3. Choose relevant skills and optional profile.
4. Run `node scripts/install.mjs ...` without `--apply`.
5. Review conflicts and planned links/copies.
6. Run again with `--apply` after approval.
7. Add or merge stack and design guidance.
8. Validate skills, links, and trigger behavior.
9. Leave changes uncommitted for review.
