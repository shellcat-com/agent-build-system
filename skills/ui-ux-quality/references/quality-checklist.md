# UI/UX release checklist

- Main task is discoverable and completable.
- Every asynchronous state has feedback and recovery.
- Repeated actions remain calm and fast.
- Destructive actions are distinguishable and appropriately confirmed.
- Content works at realistic minimum and maximum lengths.
- Text scaling does not hide actions or meaning.
- Screen-reader order matches visual meaning.
- Color is not the only state signal.
- Motion has a reduced alternative.
- Layout works at supported sizes and orientations.
- Visual tokens come from `DESIGN.md`.
- Runtime evidence covers the critical journey.
